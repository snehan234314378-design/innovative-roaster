INNOVATIVE ROASTER — WEBSITE STARTER

FILES
- index.html  Main website content
- style.css   Design and responsive layout
- script.js   Project filtering, search, copy-code button and mobile menu

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It will open in your browser.

HOW TO CUSTOMIZE
- Change text, project names and descriptions in index.html.
- Replace the sample project illustrations with your own project photos.
- Add project pages and downloadable .ino files as you build your archive.
- Edit colours and layout in style.css.

PUBLISHING
This is a static website. You can publish it using GitHub Pages:
1. Create a GitHub account and a new public repository.
2. Upload index.html, style.css and script.js.
3. In repository Settings, open Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will provide your public website address.

The four project cards and Arduino Blink snippet are examples/placeholders. Replace them with your own verified projects before presenting them as completed builds.
